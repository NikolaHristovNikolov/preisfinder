# Preisfinder

Grocery prices around Zurich in one search, cheapest per kg / l first: **https://nikolahristovnikolov.github.io/preisfinder/**

This repository only holds the published page; it is rebuilt every week.

> **Disclaimer.** A personal, non-commercial project, not affiliated with or endorsed by any of the shops. It
> shows prices the shops publish on their own websites, read gently once a week, with a link back to each
> product. Prices can be wrong or out of date; the price on the shelf counts. Shop names and logos belong to the
> shops. If you represent a shop and want something changed or removed, please
> [open an issue](https://github.com/NikolaHristovNikolov/preisfinder/issues) — it will be handled first.

Product types and names in several languages: [Open Food Facts](https://world.openfoodfacts.org) (ODbL).
Past offers: [Internet Archive](https://web.archive.org).
